# ЛР №11 — Вариант 15 (средний): Мини-викторина

**Условие:** `QuestionCard` получает данные вопроса; родитель хранит текущий индекс, ответы и счёт.

## Запуск
```bash
npm install
npm run dev
```

## Структура
```
src/
├── App.jsx                 — родитель, хранит состояние викторины
├── main.jsx                — точка входа
├── questions.js            — массив вопросов
├── components/
│   ├── Header.jsx          — шапка страницы
│   ├── QuestionCard.jsx    — карточка вопроса
│   └── Result.jsx          — итоги
└── styles/
    ├── theme.css           — общая тема (одинаковая во всех трёх проектах)
    └── App.css             — стили этого варианта
```

## Схема компонентов и данных
```
App   state: current, answers, score
├── Header         ← props: variant, title, accent, subtitle
├── QuestionCard   ← props: question, number, total, selected, onAnswer
│                     onAnswer(index) → App записывает ответ и меняет счёт
└── Result         ← props: score, questions, answers, onRestart
                      onRestart() → App сбрасывает состояние
```

| Данные | Где | Почему |
|---|---|---|
| `current` | state App | номер текущего вопроса |
| `answers` | state App | массив выбранных ответов (нужен для итогов) |
| `score` | state App | количество правильных ответов |
| `question`, `selected` | props QuestionCard | карточка только показывает данные |
| `onAnswer`, `onRestart` | props | дочерние компоненты сообщают родителю о действиях |
