# ЛР №11 — Вариант 5 (базовый): Оценка занятия

**Условие:** компонент `Rating` получает максимальный балл через props, пользователь выбирает текущую оценку.

## Запуск
```bash
npm install
npm run dev
```

## Структура
```
src/
├── App.jsx               — родитель, выводит три Rating
├── main.jsx              — точка входа
├── components/
│   ├── Header.jsx        — шапка страницы
│   └── Rating.jsx        — компонент оценки (звёзды)
└── styles/
    ├── theme.css         — общая тема (одинаковая во всех трёх проектах)
    └── App.css           — стили этого варианта
```

## Схема компонентов и данных
```
App
├── Header   ← props: variant, title, accent, subtitle
├── Rating   ← props: lesson="React: props и state", maxScore=5    | state: score, hover
├── Rating   ← props: lesson="JavaScript: ES-модули", maxScore=5   | state: score, hover
└── Rating   ← props: lesson="Базы данных: JOIN",     maxScore=10   | state: score, hover
```

| Данные | Где | Почему |
|---|---|---|
| `lesson`, `maxScore` | props | задаёт родитель, Rating их только читает |
| `score` | state | меняется при клике, интерфейс должен обновиться |
| `hover` | state | подсветка звёзд при наведении мыши |

## Тесты
| № | Действие | Ожидаемый результат | Фактический | Статус |
|---|---|---|---|---|
