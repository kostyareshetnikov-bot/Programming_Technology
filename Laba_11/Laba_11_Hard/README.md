# ЛР №11 — Вариант 19 (повышенный): Канбан-доска

**Условие:** `TaskCard` получает задачу через props; родитель хранит карточки по статусам и перемещает их кнопками.

**Дополнительно (творческое задание):** сохранение в `localStorage`, компонент аналитики `Stats`, приоритеты задач, проверка ввода.

## Запуск
```bash
npm install
npm run dev
```

## Структура
```
src/
├── App.jsx               — родитель, хранит все задачи
├── main.jsx              — точка входа
├── data.js               — колонки, приоритеты, стартовые задачи
├── components/
│   ├── Header.jsx        — шапка страницы
│   ├── TaskForm.jsx      — форма добавления (управляемые поля)
│   ├── Stats.jsx         — статистика и прогресс
│   ├── Column.jsx        — колонка доски
│   └── TaskCard.jsx      — карточка задачи
└── styles/
    ├── theme.css         — общая тема (одинаковая во всех трёх проектах)
    └── App.css           — стили этого варианта
```

## Схема компонентов и данных
```
App   state: tasks  (+ сохранение в localStorage через useEffect)
├── Header     ← props: variant, title, accent, subtitle
├── TaskForm   ← props: onAdd                        | state: title, priority, error
├── Stats      ← props: total, done, onClearDone
└── Column ×3  ← props: status, tasks, isFirst, isLast, onMove, onDelete
    └── TaskCard ← props: task, canMoveLeft, canMoveRight, onMove, onDelete
```

| Данные | Где | Почему |
|---|---|---|
| `tasks` | state App | общий список нужен всем колонкам и статистике |
| `title`, `priority`, `error` | state TaskForm | значения полей ввода нужны только форме |
| `task`, `status` | props | Column и TaskCard только отображают данные |
| `onMove`, `onDelete`, `onAdd` | props | дети вызывают функции родителя, сами props не меняют |
| `total`, `done` | props Stats | вычисляются в App из `tasks` |
