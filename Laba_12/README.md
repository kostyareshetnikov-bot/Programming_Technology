# ЛР №12 — Аутентификация и работа с токенами (JWT, OAuth): вход/выход, хранение сессии

Дисциплина «Языки и технология программирования». Три проекта в едином стиле: общая тема `theme.css` и общий `ui.js`. У каждого проекта своя серверная часть на Node.js + Express.

| Папка | Вариант | Уровень | Механизм | Порт |
|---|---|---|---|---|
| `Laba_12_Easy` | 3 — Система заметок: приватная страница и выход | Базовый | Серверная сессия, cookie HttpOnly | 3001 |
| `Laba_12_Mid` | 8 — Две роли student/teacher, проверка роли сервером | Средний | Серверная сессия + роли + аудит | 3002 |
| `Laba_12_Hard` | 17 — JWT: короткий access token, ротация refresh token, выход | Повышенный | JWT + refresh token с ротацией | 3003 |

## Запуск любого проекта
```bash
cd Laba_12_Easy      # или Laba_12_Mid / Laba_12_Hard
npm install
npm start
```
Нужен Node.js 20 или новее. Тестовые логины и пароли указаны в README каждого проекта. Это учебные учётные записи, не реальные данные.

## Общая архитектура (одинаковая во всех трёх)
```
server/                     public/
├── index.js   запуск        ├── index.html   экран входа + приложение
├── app.js     Express       ├── css/theme.css   общая тема
├── config.js  настройки     ├── css/style.css   стили варианта
├── db.js      данные        └── js/
├── password.js  scrypt          ├── api.js   запросы к серверу
├── auth.js    middleware        ├── ui.js    общие функции интерфейса
└── routes/    маршруты API      └── app.js   логика страницы
scripts/hash-password.js  хеш для нового пользователя
```
