# Задание 1. Очередь посетителей

## 1. Постановка задачи
Реализовать электронную очередь посетителей: регистрация посетителя, обслуживание первого в очереди, просмотр очереди. Обработать пустую очередь и повторную регистрацию.

## 2. Входные и выходные данные
| Входные данные          | Выходные данные |

| Имя посетителя (строка) | Сообщение о добавлении или отказе |
| Команда «обслужить»     | Имя обслуженного посетителя или сообщение «Очередь пуста» |
| Команда «показать»      | Нумерованный список посетителей в порядке очереди |
| Команда «журнал»        | Список всех операций с временем |

## 3. Обоснование выбора структуры данных
Посетителей обслуживают в порядке прихода, то есть по принципу **FIFO**. Поэтому выбрана очередь `collections.deque`:
- `append()` — добавление в конец очереди за **O(1)**;
- `popleft()` — извлечение из начала очереди за **O(1)**.

У обычного `list` операция `pop(0)` работает за **O(n)**, потому что все остальные элементы сдвигаются, поэтому для очереди он хуже.
Проверка дубликата `name in queue` работает за O(n). Для небольшой очереди это допустимо.
Журнал операций хранится в обычном `list`: в него только добавляют записи в конец.

## 4. Алгоритм
**Регистрация:**
1. Убрать пробелы по краям имени.
2. Если имя пустое, отказать.
3. Если имя уже есть в очереди, отказать (дубликат).
4. Добавить имя в конец (`append`) и записать операцию в журнал.

**Обслуживание:**
1. Если очередь пуста, вернуть `None` и записать ошибку в журнал.
2. Иначе извлечь первого (`popleft`), записать в журнал и вернуть имя.

**Просмотр:** если очередь пуста, сообщить об этом, иначе вывести всех по порядку с номерами.

## 5. Дополнительная функция: журнал операций
Каждое действие (успешное и ошибочное) записывается со временем в список `log`, его можно вывести пунктом меню 4.
**Влияние на выбор структуры:** для журнала нужен только порядок добавления и полный просмотр, поэтому подходит `list` с `append()` за O(1). Удалять из начала журнала не нужно, поэтому `deque` здесь не требуется.

## 6. Вывод
Очередь FIFO удобно реализуется через `deque`: добавление и извлечение выполняются за O(1). Программа корректно обрабатывает пустую очередь, дубликаты и пустой ввод.
